# DCXの地理情報

本文の復号結果と原電文を保持し、地理情報を確定できる場合だけ地図にします。
国内の対象区域はコードと対応する境界を使用します。政令市の区境界などが不足する場合、
上位市区や近隣区域で代用せずトピック画像へ戻します。

## 適用条件

| 通報 | 地図に使う情報 |
| --- | --- |
| 国外DCX | 確認済みCAMFの主楕円と追加範囲 |
| 国内Lアラート・自治体情報 | Vn=1、A17=0（B1）。主楕円がない場合はEX1の対象区域 |
| 国内Jアラート | 確認済みの対象区域。A17は使用しない |
| 不明版・不明区域・投影不能 | 全体をトピック表示へ切り替える |

楕円は通知対象の範囲です。中心を災害位置のピンにしたり、範囲外や避難先の安全を推定したりしません。
追加範囲の片方だけが描ける場合も、残りだけを地図にしません。

### 国内Vn=0

IS-QZSS-DCX-001〜004は国内の非NULL通報をVn=1と規定しています。
公式L1Sアーカイブ由来のfixtureにはVn=0の試験通報が存在しますが、
正式な旧仕様として全フィールドを解釈できる根拠は確認できていません。
そのためVn=1へ読み替えず、国内Vn=0はトピック表示を維持します。
NULLのVn=0や、発信機関独自の版を持つ国外DCXにはこの制限をそのまま適用しません。

根拠: [DCX-004 §4.2.4.1.8・§4.2.4.2.3](https://qzss.go.jp/en/technical/download/pdf/ps-is-qzss/is-qzss-dcx-004.pdf)、
[2024年6月の試験仕様](https://qzss.go.jp/info/information/rnhmsi0000003ltx-att/dcx_test_data_details_202406.pdf)。
fixtureの取得元と原本との関係は[受信サンプル](../tests/fixtures/qzqsm/README.md)に記録しています。

## B3の第2楕円

国外DCXの国際ライブラリA9=0・A10=0、A17=2、C10=0〜16・30・31が対象です。
以下の位置はQZQSMペイロード先頭を0としたMSB順です。

| フィールド | 開始・幅 | 解釈 |
| --- | --- | --- |
| C7 | 131・2 | 主半長軸に対する中心移動量 `s = raw` |
| C8 | 133・3 | 両半軸の倍率 `k = (raw + 1) / 4` |
| C9 | 136・5 | 主軸からの回転 `θ = raw × 11.25°` |
| C10 | 141・5 | 第2範囲への指示 |

主半軸をa・b、主方位をλとすると、主中心のENU東・北平面で第2中心は
`(s*a*cos(λ+θ), s*a*sin(λ+θ))`、半軸は`(k*a, k*b)`、方位は`λ+θ`です。
回転は中心移動と楕円の軸の両方へ作用します。C7〜C9が0でも同心1/4サイズの範囲が存在します。

地理変換は主中心のENUからWGS84楕円体への近側交差を使います。これはDCX §5.9の
主楕円の解釈を拡張した実装方針です。第2中心で別の接平面を作らず、kmを経緯度へ直接加えません。
地球面との交差がない・極を囲む・投影できない場合は全体をトピック表示にします。

重複区域では主範囲の指示を優先します。色は範囲の区別であり重大度ではありません。
**C10=0は避難先の特例**で、第2範囲と主範囲への既定指示IC-A-03を合わせて扱います。
元のA11は保持し、本文に既定指示を補足します。解除時は新しい避難行動を促す文にしません。
本文と画像の解釈は`shirasu/reports/dcx.py`で共有します。

根拠: [CAMF Issue 1.2 §3.5.2・§3.7.3・§18.3](https://www.gsc-europa.eu/sites/default/files/sites/all/files/EWSS-CAMF_in_force.pdf)。

## MTInfoの追加避難範囲

国内自治体情報（A2=111、A3=4、A9=1、A10=0、Vn=1、A17=0）を対象とします。
A11と追加指示を併用し、元の指示を上書きしません。B3の重複優先規則や既定指示は流用しません。

| フィールド | 開始・幅 | 解釈 |
| --- | --- | --- |
| EX2 | 162・1 | 0: 追加範囲から離れる、1: 追加範囲へ向かう |
| EX3 | 163・17 | 緯度 `-90 + 180*raw/(2**17-1)` 度 |
| EX4 | 180・17 | 経度 `45 + 180*raw/(2**17-1)` 度。180度超は360度を引く |
| EX5・EX6 | 197・5、202・5 | 半長軸・半短軸（下式） |
| EX7 | 207・7 | 方位 `-90 + 180*raw/128` 度。東0度・北向き正 |

半軸のkm値は`10**(log10(216.2)+raw*(log10(2500000)-log10(216.2))/31)/1000`を小数3桁に丸めます。
raw=0も約0.216kmの範囲であり、欠測ではありません。半短軸が半長軸を超える値は採用しません。
追加楕円は独立した中心を持つので、その中心を原点としたENUで輪郭を求めます。
主楕円がない場合はEX1の市町村境界と追加楕円を併せて描きます。

**EX2〜EX7の全ビットが0の場合だけ追加指示なし**です。
azarashi 0.17.1はEX3〜EX7のみでignore判定するため、EX2=1・残り0の既知ケースに限って
生値から復元します。任意の復号不一致を許す例外ではありません。
画像を描けない場合も、確認できた追加指示と受信値は本文へ残します。

根拠: [DCX-004 §4.2.4.1・§5.3.1・§5.9・§5.10](https://qzss.go.jp/en/technical/download/pdf/ps-is-qzss/is-qzss-dcx-004.pdf)。

## B4地震の追加震央

国外DCXの地震（A4=36、A17=3、A9=0、A10=0）には、主楕円とは別に震央の方向・距離を示す値があります。
**座標化の根拠が未確定なので、震央や主楕円だけの地図は表示せず、理由付きトピックにします。**

| フィールド | 開始・幅 | 解釈 |
| --- | --- | --- |
| D1 | 131・4 | リヒタースケールの区分。0〜7は1.0〜8.9、8は9.0以上、9〜15は予約 |
| D2 | 135・3 | Seismic Coefficient。2・3・4・5弱・5強・6弱・6強・7 |
| D3 | 138・4 | 主中心から震央への角度 `raw × 22.5°` |
| D4 | 142・4 | 主半長軸長に対する距離倍率 |

D4の倍率はraw順に`0.25, 0.5, 0.75, 1, 2, 3, 5, 10, 20, 30, 40, 50, 70, 100, 150, 200`。
D3=D4=0でも追加位置は存在します。D1を単一のM値やMwへ読み替えず、D2に観測・予測等の意味を補いません。
B4には震源の深さがありません。

未確認なのはD3の基準方位・回転方向・A16との関係と、D4のベクトルをWGS84へ戻す規則です。
A16やB3の方位規約を推測で流用せず、公式補足・公式実装・既知座標付き公式電文から確認してから有効にします。
実装自身の式から作った合成例だけでは、座標解釈の正しさを証明できません。

根拠: [CAMF Issue 1.2 §3.6.5・§3.7.4・§18.4.35](https://www.gsc-europa.eu/sites/default/files/sites/all/files/EWSS-CAMF_in_force.pdf)、
[Issue 1.1](https://www.gsc-europa.eu/sites/default/files/sites/all/files/EWSS-CAMF_v1.1.pdf)との表現比較、DCX-004 §4.2.4.3.2。
実装の根拠にしたCAMF 1.2のSHA-256は`609f61c2c6f881acdce1f23df0f01bd33c4a164205da4f52237571ff000eb04c`です。
